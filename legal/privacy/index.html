Privacy Policy

Stub privacy notice for a fan site. Not legal advice. We may update this page as auth, ads, or paid features land.

Last updated: August 2026

What this site stores

Core game catalog and published builds live in our Supabase project (database + related storage). We do not run third-party ads on these pages. Accounts use Discord OAuth via Supabase Auth (no email/password signup on this site).

  • Builds — title, tags, board placements, route notes, optional video link, moderation flags, author link
  • Profiles — Discord user id, display name, avatar URL, optional bound vote key, owner flag (for site admins)
  • Votes — anonymous voter_key in local storage + server vote rows; bound to your profile after Discord sign-in when possible
  • Local drafts — create-page drafts may stay in your browser (localStorage) until you submit or clear them
  • Combat sandbox — dummy fights on /sim/ run in your browser. We do not store fight results on the server. The page may keep a mode preference in localStorage (bpb-sim-mode)

Discord accounts

Signing in with Discord creates a Supabase session and a public profile page at /u/{discord_id}/. We store the Discord snowflake, display name, and avatar URL so we can credit builds and show your persona. Submitting a build requires a signed-in Discord session. You can sign out from the site nav. Deletion requests for a profile or published builds: contact us via Discord or YouTube (see Contact).

Steam history.db uploads

If you attach a Steam history.db run in the creator, we may store run metadata needed to show a Real build and round scrubber — for example board layouts per round, win/loss markers, class/league display fields, and related item placements. We use this to power the site experience, not to sell your history.

  • Retention — kept with the draft/build while the history remains attached
  • Clear / unlock — clearing run history on create removes the attached history from that draft (Real → Feasible)
  • Deletion requests — contact us via Discord or YouTube to request removal of a published build, attached history, or account profile data

Votes

Likes/dislikes use a key in your browser plus server-side vote records. Before sign-in the key is anonymous (bpb-voter-id). After Discord sign-in we bind that key to your profile when possible so votes follow your account across devices. Clearing site data before binding can create a new key.

Hosting & logs

The static site is hosted on GitHub Pages (and may sit behind a CDN). Standard hosting and database provider logs may exist for security and reliability.
