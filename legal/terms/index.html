Combat sandbox reports

The optional Report issue form on the combat sandbox sends a description plus frozen session facts (seed, board, opponent, permalink) so we can investigate sim bugs. Site owners review those reports on a private admin page. Do not put secrets or unrelated personal data in the description. See Privacy.

History uploads

Optional Steam history.db uploads are used to attach real run history to a draft or published build. Only upload files you are allowed to use. See Privacy for what we store.
