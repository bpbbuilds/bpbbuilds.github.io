# Documentation map

This directory replaces the feature-specific documents that formerly lived in `docs/features/screenshot-detector.md` and `docs/screenshot-import-perfection.md`.

The following documents intentionally remain outside this folder because they are shared project records, not canonical feature documentation:

- `docs/CURSOR_HANDOFF.md` and `docs/CODEX_HANDOFF.md` retain dated historical handoff facts.
- `docs/features/deploy-cache.md` is a general cache/stamping document; it mentions screenshot modules only where they affect the shared deployment process.
- `docs/todo.md` may contain product planning references.

For code and research artifacts, see [ARCHITECTURE.md](../ARCHITECTURE.md) and [experiments/README.md](../experiments/README.md).
